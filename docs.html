LEXORA DEVELOPER PLATFORM

Build with intelligence.

Lexora provides language intelligence infrastructure for applications, AI systems and data pipelines. Send language data through a simple developer API and receive structured results.

API V1

HTTPS · JSON · Bearer authentication

01 / QUICK START

Make your first request.

Every Lexora request uses HTTPS and JSON. Authenticate using your Lexora API key and send your input to the intelligence endpoint.

CURL 
curl https://api.lexora.ai/v1/intelligence \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Analyse this document.",
    "language": "en"
  }'

Base URL 

https://api.lexora.ai
02 / AUTHENTICATION

Secure every request.

Lexora uses API keys to authenticate server-to-server requests. Include your key in the Authorization header.

AUTHORIZATION 
Authorization: Bearer YOUR_API_KEY
Keep your API key private.

Never expose secret API keys in browser JavaScript, public repositories or client-side applications.

03 / INTELLIGENCE

Language intelligence.

Analyze language through one unified endpoint. Provide text, language and the intelligence tasks you need.

POST /v1/intelligence

Run language intelligence tasks on an input document or text payload.

FIELD TYPE DESCRIPTION
text string Input language data.
language string Language code such as en.
tasks array Requested intelligence operations.
REQUEST 
{
  "text": "Analyse this document.",
  "language": "en",
  "tasks": [
    "classification",
    "entities",
    "summary"
  ]
}
04 / DATASETS

Process language datasets.

Run structured and unstructured language data through Lexora pipelines.

POST /v1/datasets/process

Process a dataset through the Lexora language intelligence pipeline.

EXAMPLE RESPONSE 
{
  "status": "success",
  "request_id": "lxr_01...",
  "results": {
    "language": "en",
    "confidence": 0.98
  }
}
05 / RESPONSES

Predictable responses.

Successful requests return a structured JSON response containing request metadata and intelligence results.

200 OK 
{
  "status": "success",
  "request_id": "lxr_01...",
  "results": {
    "language": "en",
    "confidence": 0.98
  }
}
06 / ERRORS

Errors that explain themselves.

When a request fails, Lexora returns a structured error object containing a machine-readable code and a human-readable message.

ERROR RESPONSE 
{
  "error": {
    "code": "invalid_api_key",
    "message": "API key is invalid."
  }
}
CODE MEANING
invalid_api_key The supplied API key is invalid.
unauthorized Authentication is required.
invalid_request The request payload is invalid.
server_error Lexora could not complete the request.
